## Conflicts with the brief that were resolved by choosing the brief

- `CLIENT_SEES_DRAFT_FINDINGS=true` (owner's decision, 2026-11) conflicts with "clients see approved findings and appropriately labelled provisional observations". Kept: drafts are labelled "Draft · not yet reviewed", and only while the assessment is live.
- The metering report's PV/battery sizing (built 2026-11-06 at the owner's request) conflicts with "GridIQ does not build PV/battery sizing". Now off unless `FEATURE_TOOLS=true`; the report shows a handover note instead.
- Legacy projects: no assessment is invented for them. Clients of an existing project see no data until staff create an assessment with real dates (the demo seed creates labelled ones).
